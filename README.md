# Демо 7cars: застосунок клієнта + панель керування

## Онлайн
- GitHub Pages: https://pankratovnazar2009-gif.github.io/7cars/ (режим презентації: `/#split`)

## Запуск локально
1. Потрібен Node.js (вже встановлений на цьому ПК).
2. Двічі клацнути **«Запустити демо.bat»**. Відкриється браузер у режимі презентації.
   Або вручну: `node server.js` → http://localhost:5173
3. Потрібен інтернет для карт (Esri) і маршрутів (OSRM). Фото авто лежать у `assets/`: студійні вирізки зроблено з фото 7cars.com.ua нейромережею локально.

| Адреса | Що це |
|---|---|
| `/` | Стартова сторінка |
| `/#split` | **Режим презентації**: телефон і адмінка поруч, синхронізовані наживо |
| `/app/` | Застосунок клієнта в рамці телефону + сценарій показу збоку |
| `/admin/` | Панель керування менеджера |

На ноутбуці для показу найкраще відкрити `/#split` на весь екран (F11).

## Сценарій показу (≈5 хв)
Кнопки сценарію є праворуч від телефону в `/app/`.
1. **AI-підбір**: «Вчотирьох у Карпати на 3 дні до $70». AI бере авто з парку 7cars і рахує ціну за тарифом тривалості.
2. **Бронювання**: тарифи 1–3 / 4–9 / 10–29 / 30+ днів, додаткова страховка зменшує заставу, доставка безкоштовна від 3 діб, Apple Pay / Google Pay, Дія як планована інтеграція.
3. **Подача наживо**: авто їде реальними вулицями Києва (маршрут OSRM). В адмінці воно рухається на карті з ETA.
4. **AI-огляд**: 4 фото, AI фіксує стан авто. Захищає від суперечок щодо пошкоджень.
5. **Цифровий ключ**: утримати, щоб відчинити. Режим Bluetooth без інтернету, клімат, багажник, «знайти авто», продовження оренди.
6. **Чат по конкретному авто**: повідомлення одразу з'являється в адмінці. Якщо адмінка закрита, відповідає автовідповідач.

В адмінці: жива карта всієї України, алерти (прострочка, перевищення швидкості, геозона, мало пального), таймери повернення, дистанційні дії (зачинити, сигнал, продовження −10%, блокування двигуна), шахматка бронювань, AI-аналітик, дохід кожного авто порівняно з середнім.

**Скинути демо**: кнопка «Скинути демо до початку» в `/app/`.

## Що реальне, а що демо
- Справжні дані з сайту 7cars: 30 авто (по 5 з кожного класу: економ, середній, бізнес, преміум, позашляховики, мінівени), фото, характеристики, тарифи й застави, умови оренди, адреса, телефони, курс 46,30.
- Згенеровані дані: номери, клієнти, телеметрія, виручка, рейтинги.
- AI працює на власній базі, без зовнішньої моделі: розбирає запит і підбирає авто з парку за правилами.
- Дія тільки позначена як наступний етап.

## Структура
- `shared/` — дизайн-токени, дані автопарку, симуляція телеметрії, синхронізація між вкладками
- `app/` — застосунок клієнта (`ai.js` — AI-помічник)
- `admin/` — панель керування
- `research/features-2026.md` — ресерч фішок конкурентів
